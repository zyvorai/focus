Questions, answered.

What exactly does a profile do?

It places windows where you saved them, opens terminal windows in a folder with a command, opens browser tabs, connects or disconnects a VPN, and switches the kube context. Every part is optional, and each profile can have its own hotkey.

Can I see what it will do before it does it?

Yes. Dry Run in the editor, or FocusProfiles --dry-run, prints every step and what would be skipped for missing permissions. It moves nothing, launches nothing and prompts for nothing.

Which permissions does it ask for?

Accessibility, to move windows, when you first switch a profile that places windows. Automation, per app, the first time a profile opens a window or tabs in Terminal, iTerm2, Safari or Chrome. If you refuse, only those steps are skipped and reported.

Does it send anything over the network?

No. It contains no networking code, and its only entitlement is Automation. Check it yourself with codesign -d --entitlements - "/Applications/Focus Profiles.app". It is not sandboxed.

Does it read my windows, tabs or terminal output?

No. It moves and resizes windows and asks apps to open new windows and tabs. It does not read their contents, record the screen or watch keystrokes.

Where are my profiles stored?

As plain JSON files, one per profile, in ~/Library/Application Support/Focus Profiles/Profiles/. Edit them in the app or by hand.

Is there a trial?

Yes: a 30-day trial key from sales@zyvor.dev. Without a key everything still works.

What happens without a key, or when a trial ends?

Nothing is disabled. A status line shows where your licence stands.
